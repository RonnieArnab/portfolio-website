# Small, meaningful additions

These are suggestions, not implemented features. Start with one and keep it small.

1. **Travel Buddy walkthrough — strongest fit.** Use one sample travel clip and
   show the extracted places, the fallback path, and the resulting itinerary.
   Three selectable steps connect an existing project to a real interest in travel.
   A static example is enough; no live API or upload flow is necessary.
2. **Build notes.** Add short notes about one engineering decision per project:
   the problem, the tradeoff, and what changed. Two or three notes can demonstrate
   judgment more clearly than another interactive feature.
3. **Travel field notes.** Pair selected gallery photos with a short memory or
   observation written by Arnab. A simple photo-and-caption list keeps the
   personal side of the site without introducing another app inside it.
