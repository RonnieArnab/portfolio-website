# Reuse this portfolio pattern

Create a personal engineering portfolio using React and Vite. Keep professional
experience and contact information grounded in supplied résumé content. Use a
warm cream background, plum text, muted lavender accents, and yellow primary
buttons. Use a consistent system font, 16–17px body text, 14–16px control labels,
and 12px minimum secondary labels. Keep pointer targets at least 44px, support
keyboard focus and browser zoom, and respect reduced motion.

Include a photo gallery, a short introduction, optional conversational prompts,
project stories with expandable technical notes, a selectable experience timeline,
and a skills overview linked to concrete work. Use simple native disclosures and
links wherever possible. Keep hobby content personal and lightweight. Contact
and assistant dialogs should trap keyboard focus, support Escape, and restore
focus on close. Do not invent résumé facts or publish without authorization.
